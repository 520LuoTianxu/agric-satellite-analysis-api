# T6 双周报后台离线逻辑（已批准范围）

遵循t31/t32：仅编写后台逻辑，前端PR17保持Mock，等待明确对接指令；不注册真实路由、启动监听/定时器、调用生产源/AI/OSS或执行迁移。

采用共享纯领域核心 + API侧应用服务/本地离线仓库 + 下载侧单次worker。API负责field_id=landId的授权、源适配、不可变快照、幂等任务/租约/重试/失效、下载鉴权。worker仅经WorkGateway消费冻结输入、验证结构化文案、渲染中文PDF及内容寻址产物，不访问数据库或Redis。SQLite仅为显式离线API控制面实现，绝不作为下载机接API数据库的途径。

快照包含租户/地块/种植季、半开双周窗口、源版本/资产指纹、模拟或真实标记、计划BTU阶段及映射版本、紧凑指标/天气证据、缺失与质量标志。阶段由显式适配器提供计划窗口，不能当实测物候。冬小麦/玉米试验策略、按起始日主归属跨期只归档一次；未知作物/映射拒绝，缺排期允许受限报告且明确缺失。

FVC无校准样本、LAI无批准模型，均不进入可解释事实（保留输入审计及缺失标记），不反演、不补零。质量阈值仅离线试验策略，不是生产农学标准。必须缺失显式、数值有限、单位/范围/窗口合法。

AI为注入端口，不选择或调用模型。默认无AI模板明确标注。结构化输出需证据引用、数值与单位精确匹配；自由文本不允许数字/中文数值表达或危险定性，拒绝无证据/假数值。语义审查并非科学证明，正式启用仍需模型/预算/策略审批与人工验收。

不可变快照内容寻址；job键含snapshot/template/prompt/model/language。queued→running→ready/failed，有限重试，随机租约令牌/过期隔离旧worker；源失效后不再发放下载/完成/重试。API每次访问重新检查租户和地块权限，默认关闭且DenyAll。

安全发现：现有`services/api/app/middleware/auth.py`明确AUTH_DISABLED且匿名绕过，因此不能复用为租户授权。新服务不挂载路由；真实JWT与地块归属适配器是对接前置阻塞，不在本轮偷偷修改旧鉴权。

复用ReportLab依赖及已有中文字体；不复用会自动读环境/连网/查库的旧报告编排或Bailian函数。离线CLI只读明确指定的Mock JSON，写用户指定的新输出目录；不会发布Celery/MQ任务。后续内部HTTP/生产持久化/OSS/阶段API仍为待实现适配器。

应用入口本轮只接受data_kind=mock；real枚举仅为未来契约保留，不能据此运行真实输入。详见`docs/biweekly-offline-backend.md`运行手册。
